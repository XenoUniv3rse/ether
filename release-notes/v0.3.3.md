# Ether v0.3.3

## Plugins and Studio

Ether now has a plugin system. Plugins add real things to the server — Live TV channels, video sources, catalogues, metadata, subtitles and Home rows — and appear where those features already live rather than on separate pages.

- **Studio** builds plugins from a plain-language description, with a live preview on your own library, or lets you edit the code directly with a built-in reference.
- **Stremio add-ons** can be installed from their link and become ordinary, fully editable plugins. Add-ons with their own settings page can be configured from inside Ether.
- **Native debrid provider** plugins can supply cached torrents through Ether's normal debrid playback.
- Six example plugins are included as source examples; none are installed automatically.
- Each installed plugin shows its health, what it adds, its setup and its recent activity.
- The Model Context Protocol (MCP) integration lets AI apps use the same plugin and collection tools.

## New in the owner console

- **Activity › Experience** shows how playback is going for each viewer: start time, buffering, failed starts, delivered bitrate, most-used device, hours watched, direct play versus transcode, and source switches, with a plain-language likely cause. Start time and buffering are measured from this version on.
- **Playback › Pre-rolls** plays your own short videos before movies or episodes. Rules cover viewers, genres, collections, ratings, dates, home or away, devices, frequency, and the first episode of a session. *What would play?* shows which pre-roll wins for a viewer and title, and why. Existing Plex Media Server pre-roll settings can be imported.
- **Describe a collection** builds a collection from a sentence, showing the posters and each step as it works. A build continues if the browser disconnects, and the result can be saved, refined or opened in the editor.
- **Library › Catalog** can add titles to your own or a household viewer's watchlist, synced to linked Trakt accounts.
- **TMDB user lists** can be used as a collection source.
- Quality profiles have a **Custom score** step that can be placed anywhere in *What matters most*.
- The indexer **Client identity** card shows the exact user agent each choice sends. Contributed by @evulhotdog.
- Cache Explorer explains where each cached release came from, and Activity shows read-ahead. Contributed by @evulhotdog.
- The console splash animation can be turned off under Server › General.
- Playback now appears directly under Sources in the sidebar.

## Indexers

New-release detection now works the way Radarr and Sonarr do, and Ether is far gentler on indexers.

- Each indexer's RSS feed is read every 30 minutes and matched locally against movies waiting for a release, so new movies typically appear within half an hour of a release being posted.
- Title searches happen only on events, such as a movie entering the release window, never on a timer. Background searches ask one indexer at a time and stop at the first usable release. Playback still searches every indexer at once.
- Background work is limited to a small share of each indexer's daily limit, learned from the indexer when it reports one or set on the indexer. Requests are spaced out, and Retry-After and limit errors are honoured.
- A downloaded NZB is reused from disk instead of being fetched again. Indexer statistics now count only downloads the indexer actually served.
- Built-in torrent sites gain a "latest releases" feed.

## Plex and other apps

- **Faster Plex pages:** detail pages, post-play and search no longer write to the database or wait on TMDB while loading, and Home rows avoid repeated per-item queries.
- **Subtitles:**
  - Embedded subtitles now show on Plex for Android, Android TV and Plex Web.
  - Subtitles stay in sync after resuming or seeking.
  - ASS subtitles are burned in correctly when Plex Web asks. Docker images now include fonts for this.
- **Player stability:**
  - Plex Web and Plex for Mac keep a stable set of versions and tracks for the whole playback session, which fixes intermittent settings-panel crashes.
  - A play request the app abandons no longer fails the next one.
- **Dolby Vision** profile 7 and 8.1 releases play on Plex for iOS as their HDR10 base layer when the app asks for Matroska. A start that never begins playing now ends with a clear message, and an HDR10 retry where possible, instead of an endless spinner.
- **Silo:** Silo for Android TV can play titles; identifiers now fit the Android client's limits.
- **Other Plex apps:**
  - Plex for Kodi (PM4K) can play titles.
  - Plex for Apple TV no longer reports "Unavailable Media" before playback. Contributed by @Neoo-Blue.
  - Plex Web's Advanced Filters open correctly.
  - Per-library Home rows and the Recently Added row are fixed.
  - Duplicate and floating covers when scrolling long rows are fixed.
- **Watch state and history:**
  - Plex account watch state can be set to send, import on a schedule, or both, with clear reasons when Plex refuses.
  - Watch history now records one row per viewing instead of one per player request.
- **Debrid:** a title with no cached copy now explains why it cannot play, and with *Cached torrents only* off, Ether queues one download and follows it until it plays.
- **Metadata:** cast and crew are matched to the correct title, rating badges have more options, and mixed collections show only movies in Movies and only shows in TV Shows.

## Reliability

- Upgrading a large library no longer takes Ether offline for minutes while the database updates.
- Ether starts on any filesystem it can verify, including OrbStack and Docker Desktop volumes. Where cache cleanup cannot be fully trusted it runs in a cautious mode, and the console explains why. The database is refused only on network shares and Unraid user shares.
- PostgreSQL clusters: several PostgreSQL-only errors are fixed, including catalogue sync for movies dated before 1902, release-feed sync and jump-bar order. Restoring a backup into PostgreSQL now completes quickly on large libraries.

## Upgrade notes

- Background indexer limits now default to a small share of each indexer's daily limit. If you set a daily limit on an indexer, Ether uses it.
- Pending release checks from older versions are reset on upgrade so the new schedule starts cleanly; nothing is re-searched in a burst.
- Pre-rolls and plugins are off until you add them.
- Watch history rows created before this version stay as they were; zero-byte rows no longer count as plays.
- Docker images now include a font package for burned-in subtitles. Headless tarball installs on Linux need `fontconfig` and a font installed for the same feature.
