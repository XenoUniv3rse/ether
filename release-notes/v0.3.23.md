# Ether v0.3.23

Highlights:

- **Continue Watching is back for everyone.** Since 0.3.21, a Home row that only one viewer could see removed that row type for every other viewer, so Continue Watching disappeared for most of the household (#844, thanks @kraigeisenman).
- **Infuse opens titles again.** Opening a film or episode in Infuse through Ether's Jellyfin connection failed with "Unexpected server response" since 0.3.21 (#845, thanks @ch1ptune).
- **Faster provider posters.** BetterPosters and other poster providers load quickly in big grids, and a poster Ether already has never waits on the provider (#846, thanks @kraigeisenman).
- **AMD Radeon hardware transcoding done right.** HDR to SDR conversion uses the GPU when that's faster, and Ether picks working paths for Radeon, Intel and NVIDIA by testing them, not by guessing.
- **Music playlists in Plex.** Plexamp and Plex Web's music Playlists tab now show and create audio playlists (#843, thanks @machetie).

## Playback and apps

- **Jellyfin and Emby** (Infuse and others):
  - every version of a title carries its file path, container, size and audio and subtitle tracks, on detail pages, playback info and extras;
  - item JSON always gets a full response, never a bare "not modified";
  - checking a playback URL (HEAD) returns the real file headers;
  - a byte-range request is never answered with a whole file after a source failover (#845).
- **Seeking right after starting** no longer fails with a server error: a segment request that races the restart is served from the new stream or asked to retry.
- **Plex Companion:** players that relay remote control through their server, such as Plex for Samsung TVs, can now be cast to and controlled through Ether from the phone app, Plex Web's "Play on" and scripts. Each viewer reaches only their own players (#837, thanks @jmiller0).
- **Music playlists in Plex:** audio playlists list, play and can be created from tracks, with add, remove and reorder. A music plugin's list levels appear as read-only playlists, and Jellyfin and Emby show the same playlists as audio (#843).

## Live TV

- **Catch-up library** (thanks @kraigeisenman):
  - Plex apps show catch-up artwork (#839);
  - an airing without an episode title is named by when it aired, in your language ("Wed Nov 25, 6:30 PM"), instead of repeating the show name (#840);
  - the library sorts by title, newest or oldest, in Plex, Jellyfin/Emby and Silo (#841);
  - search finds catch-up airings: Plex adds a Catch-up hub after On TV (#842).

## Home and rows

- **Rows with an audience** only take over their row type for the viewers in that audience. Everyone else gets Ether's normal row, on Home and every library's Recommendations page. Existing pages heal when they load, with nothing to change (#844).

## Transcoding

- **AMD Radeon (VAAPI):**
  - **HDR to SDR** on the GPU through Vulkan (libplacebo) when the Radeon driver has no VAAPI tone-mapping. Ether measures the CPU and GPU routes once, then picks the faster one per stream, moving to the GPU when the CPU is busy, and declines a stream that neither route can keep up with;
  - if the GPU ever reports a lost device, Ether stops using that route on that GPU until restart and falls back to the CPU;
  - hardware deinterlacing is only used once Ether has checked it actually removes combing;
  - subtitle burn-in works where the driver lacks `overlay_vaapi`;
  - AV1 hardware decoding is detected correctly;
  - 10-bit HEVC and the bitrate cap are probed and respected.
- **Hardware probing:** Intel Quick Sync is only probed on Intel GPUs, expected probe failures aren't logged as warnings, and Ether uses the GPU that passes an encode test when there are several. The Playback page shows the route chosen for the latest HDR conversion.

## Posters and artwork

- **Provider posters** (BetterPosters, PostersPlus, XRDB, RPDB, PosterFlow and custom templates):
  - several are fetched at once per provider, instead of two for the whole server;
  - a stored poster is served at once and refreshed in the background;
  - waiting for a fetch slot no longer counts against the timeout, so busy grids don't fall back to TMDB art (#846).
- **Artwork at the size apps ask for:** Plex, Jellyfin, Emby, Vela, Silo, Stremio and Xtream clients get posters, backdrops, logos and thumbnails scaled to the requested size, never upscaled, and cached once per size. A 640-pixel backdrop is now about 4 KB, where it used to be the 80 KB original.

## Console

- **Trusted proxies by name** also work when the system resolver can't see Docker container names (for example behind a Cloudflare WARP container): Ether asks Docker's own DNS, only when it's running inside Docker. Entries may be written as URLs (#835, thanks @EsmailELBoBDev2).

## Viewer portal

- **Invite links:** an invite link only invites. Accepting asks for a username and password straight away, so closing the tab can't lock a new viewer out, or they can use their Plex account instead. A used or expired link says so. The TV-code screen says which account is signed in. Jellyfin's sign-in page gives a hint about usernames and Quick Connect without revealing any (#834, thanks @EsmailELBoBDev2).

## Reliability

- **Flows:** reloading flows no longer races a running flow's result.

## Upgrade notes

- **Vela 0.2.77** or later is recommended.
