# Ether v0.3.23.1

A hotfix for v0.3.23.

- **Trailers play again in Vela.** Opening a trailer's live session events ended the trailer session straight away, so its media link stopped working before the player could load it: Vela web stayed black at 0:00 and Apple TV said "Trailer unavailable". Trailer sessions now stay alive for as long as their grant allows (#869, thanks @Motley-Brew).

## Upgrade notes

- **Vela 0.2.79** or later is recommended.
