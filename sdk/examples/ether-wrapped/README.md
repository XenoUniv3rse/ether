# Ether Wrapped

Explore a granted viewer's completed titles for the current year, with a monthly chart, top genres and a poster grid. Choose viewers at installation and select one on the page. Add “Your year in titles” in a collection and choose a viewer and optional year.

Screenshot placeholder: Wrapped page with viewer buttons, two stat tiles, posters, genres and a monthly chart in light and dark themes.

## Limits

The page reads the most recent 200 history entries, so older activity can be omitted. The chart counts completed history entries and does not estimate viewing time. Collections include only titles with an IMDb identifier. A viewer grant is required and can be revoked at any time.
