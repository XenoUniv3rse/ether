# Dub language

Adds a release ranking step and a language condition. In Releases, add the step to a profile and enter ISO language codes in preference order. The first matching language wins; MULTi counts for every selected language. Conditions accept an ISO code or list of codes.

Screenshot placeholder: Releases profile drawer showing the ordered audio languages and the step in the ranking ladder.

## Limits

Release names and indexer language tags are imperfect. A language tag does not prove that a track is a dub, and DUB alone does not identify its language. Untagged releases receive no preference. This plugin makes no network calls.
